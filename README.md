# 🏦 Bank Customer Churn Analysis

## 📌 Project Overview
This project analyzes customer churn patterns to understand customer behavior and identify groups with higher churn rates.

## 🎯 Project Objectives
- Analyze the customer churn rate.
- Identify age groups with higher churn.
- Compare churn based on credit card ownership.
- Analyze churn by number of banking products.
- Explore customer balance and salary patterns.

## 🛠️ Tools & Technologies
- **Microsoft Excel:** Data cleaning and analysis.
- **Power BI:** Interactive dashboard and data visualization.

## 🔄 Project Workflow
1. **Data Cleaning:** Cleaned and prepared the dataset using Excel.
2. **Data Analysis:** Explored customer data and churn patterns.
3. **Data Visualization:** Created charts and visualizations using Power BI.
4. **Dashboard Development:** Built an interactive dashboard to explore customer churn.

## 📊 Key Analysis
- Customer churn rate.
- Churn by age group.
- Churn by credit card ownership.
- Churn by number of products.
- Average estimated salary by churn status.
- Customer balance versus age.

## 💡 Business Value
The analysis helps identify customer groups with higher churn rates and highlights areas where the bank could investigate customer retention strategies.
